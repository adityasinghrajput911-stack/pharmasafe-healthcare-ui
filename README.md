# 🏥 PharmaSafe: Smart Healthcare Companion

PharmaSafe is a progressive web application designed for the Indian healthcare context. It solves the critical problem of **polypharmacy** (taking multiple conflicting medicines) and prevents dangerous drug-food interactions by generating smart daily schedules and providing verified, safe diet guidelines.

Built with a focus on elderly accessibility, the app features a highly professional, flat enterprise UI with premium Framer Motion micro-interactions.

## ✨ Core Features
* **Multi-Medicine Smart Schedule:** Users can input multiple daily medicines (e.g., Dolo 650, Telma, Pan-D). The app automatically separates clashing drugs and builds a safe daily timetable (Morning/Afternoon/Night).
* **3-Tier Traffic Light Diet Guide:** A highly scannable, Blinkit-style interface that tells users exactly what foods to Avoid (Red), Space Out (Yellow), or Enjoy (Green) based on their specific prescriptions.
* **Live Internet Cross-Check:** Replaces confusing medical jargon with a 1-tap verification system that cross-references advice against standard online health portals.
* **Symptom Relief & First-Aid:** Provides immediate, safe home remedies for late-night emergencies with strict "Red Flag" warnings for when a doctor is mandatory.
* **Grounded AI Copilot:** A context-aware chatbot that explains medical interactions in plain language without hallucinating diagnoses.

## 🛠️️ Technical Architecture
* **Frontend:** React / Next.js
* **Styling:** Tailwind CSS (Strict Light/Dark Mode enforcement, Flat Enterprise Aesthetic)
* **Animations:** Framer Motion (Magnetic hover, spring-based tap physics, fluid height expansion)
* **Data:** Localized Indian Pharmacy Mock API for instant, crash-proof searches without latency.

## 💡 The Philosophy
Healthcare should be as simple as reading a newspaper. PharmaSafe empowers patients to take control of their daily health routines with zero cognitive load, turning complex pharmacological data into actionable, safe daily habits.
